# atlantis-soc-docs

## Overview

Documentation related to the Atlantis System-on-Chip (SoC) utilizing the TT-Ascalon CPU Cluster.

## Getting Started

The Atlantis SoC data sheet is available in [`data_sheet/atl_soc_data_sheet.pdf`](data_sheet/atl_soc_data_sheet.pdf).
